### Investigation

Read [the OMP runtime contract](../references/omp-runtime.md) first and [the main entrypoint](../SKILL.md).

**Own a cited answer, not a code change.** This workflow is read-only.

1. Read `/skill:pstack-how`; for motivation also read `/skill:pstack-why`. Use the narrowest known sources and read-only native tools.
2. Keep the throughput checkpoint to `throughput checkpoint: n/a, read-only investigation`.
3. Produce Overview, Key Concepts, How It Works, Where Things Live and Gotchas, or a recommendation with an alternatives/tradeoffs table.
4. Apply `/skill:pstack-unslop`. Distinguish source facts, inference and unknowns, and link only evidence actually read.

No PR, remote issue, babysit, prototype or implementation is authorized by this playbook. If a code change is desired, report the answer and proposed route; only an implementation request switches to Bug fix or Feature. Architecture exploration is not an excuse to mutate a read-only task.

**Reply:** cited explanation or recommendation, real judgment and reasons, including premise corrections when warranted.
